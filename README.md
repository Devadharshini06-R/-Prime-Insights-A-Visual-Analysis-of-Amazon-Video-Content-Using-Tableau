
# 📊 Amazon Prime Video Content Analysis Dashboard - Tableau Project

### 📝 Project Description

This Tableau Dashboard provides an in-depth analysis of the movies and TV shows available on **Amazon Prime Video**. The data visualization helps to understand the distribution of content, ratings, genres, release trends, and geographic diversity of the titles available on the platform.

The insights are derived from the dataset `amazon_prime_titles_.xlsx` and visually represented using various Tableau charts and maps.

### 📁 Dataset Used

- **File Name**: `amazon_prime_titles_.xlsx`
- **Source**: Dataset containing details of Amazon Prime content including title name, type (movie/show), release year, duration, rating, date added, country, and genre.

## 📊 Key Features of the Dashboard

### 🔍 **Title Details**
- Displays metadata of the selected title (e.g., “2ELEVEN”) such as:
  - **Duration**
  - **Release Year**
  - **Date Added**
  - **Rating**
  - **Genre**
  - **Description**

### 🎥 **Movies & Shows Distribution**
- Total count and percentage of:
  - **Movies**: 7,814 (≈81%)
  - **TV Shows**: 1,854 (≈19%)

### 📈 **Ratings Distribution**
- Bar chart showing how many titles fall under each content rating (e.g., 13+, 16+, 18+, PG-13, etc.)

### 📆 **Total Movies & TV Shows by Year**
- Area chart showing the number of titles added each year from **2018 to 2023**
- Trend shows peak content addition around **2019–2021** and a drop in 2023

### 🌍 **Geographic Distribution**
- World map showing the count of movies and shows by country of origin
- Highlights regional contributions (e.g., US, India, UK)

### 🏷️ **Top 20 Categories**
- Horizontal bar chart showing the most frequent genre combinations
  - Top categories include: Drama, Comedy, Suspense, Animation, Kids, etc.

## 📌 Tabs in the Dashboard

- **TOTAL MOVIES AND TV SHOWS**
- **TOTAL MOVIES & TV SHOWS BY COUNTRY**
- **TOP 20 CATEGORY**
- **MOVIES & SHOWS DISTRIBUTION**
- **RATINGS**
- **DESCRIPTION**
- **DATE ADDED**
- **DURATION**
- **RELEASE YEAR**
- **GENRE**

Each tab provides focused insights based on specific attributes of the dataset.

## 📈 Tools Used

- **Tableau Public** – For creating interactive visualizations and dashboards.
- **Microsoft Excel** – For data cleaning and preparation.

## 📚 How to Use

1. Open the Tableau dashboard using **Tableau Public Desktop**.
2. Use filters such as:
   - **Type**: Filter by Movie or TV Show
   - **Title**: View individual content metadata
3. Navigate through different tabs to explore various dimensions of the content.
4. Hover over visuals for detailed tooltips.

## 📌 Conclusion

This dashboard allows users to easily explore the Amazon Prime Video content library, spot trends in content addition, identify popular genres, and understand distribution by country and rating. It's helpful for content strategists, entertainment analysts, and data visualization learners.
